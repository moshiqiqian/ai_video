# 文案写法

## 时长换算

中文 TTS 约 **4.5 字/秒**（含停顿）。

| 目标时长 | 字数 | 适合 |
|---|---|---|
| 15 秒 | 60–70 字 | 抖音爆款、金句 |
| 30 秒 | 120–140 字 | 常规短视频 |
| 45 秒 | 190–210 字 | 时评、科普 |
| 60 秒 | 260–280 字 | 深度点评 |
| 90 秒 | 380–420 字 | 长视频 |

**先定时长再写字数。** 写完再删是最费时的做法。

## 结构模板

### 时评 / 观点

```
钩子      一句反常识或冲突，把观众钉住
事实      发生了什么，给关键数字
解读      为什么会这样，谁受影响
观点      你的判断，明确站边
```

示例（约 200 字，45 秒）：

> 央行又降息了，但这次和以往不一样。
> 表面看是放水，实际是在给银行减负。
> 存款利率会跟着降，你的理财收益也会少一截。
> 真正的风险不是降息，是降息之后没人愿意借钱。
> 钱在银行里转圈，不进实体，这才是问题。

### 科普 / 解释

```
问题      观众不知道但应该知道的
答案      一句话回答
拆解      分层解释（2–3 层）
收尾      一句话总结
```

### 产品 / 介绍

```
痛点      用户现在的麻烦
方案      你的东西怎么解决
能力      三条具体的
行动      下一步做什么
```

## 写作规则

| 规则 | 原因 |
|---|---|
| 单句 ≤ 40 字 | 超过 TTS 会呛气，听感断裂 |
| 数字用阿拉伯数字 | “3200 亿”比“三千二百亿”念得准 |
| 每段至少一个句号 | 没有标点就没有停顿，时间轴切不开 |
| 少用括号和引号 | 部分 TTS 会念出来 |
| 英文词控制在一句一个 | 中文模型读英文名容易错 |
| 不要用“如下”“见图” | 视频没有图可看 |

## 常见问题

**字数对了但还是长短不一**
→ 内容密度不同。数字多的段落念得慢，适当减少。

**念出来很生硬**
→ 句尾全是句号。把一部分改成逗号，让语气连起来。

**TTS 念错专有名词**
→ 换成中文谐音写，或者接受（字幕用原文）。
