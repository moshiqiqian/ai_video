# 导入文稿的规则

## 支持什么

`.md` / `.txt`，UTF-8 或 GBK 都能读（读不出会替换为占位符）。

## 自动清洗

| 内容 | 处理 |
|---|---|
| `---` frontmatter | 剥离，但提取 `title` 作候选标题 |
| 代码块 ` ``` ` | 整段删除 |
| 图片 `![](path)` | 记录路径到候选，正文删除 |
| 链接 `[文字](url)` | 只留文字 |
| HTML 标签 | 删除 |
| 脚注 / 引用编号 | 删除 |
| 表格 | 保留文字，可能读起来像清单 |
| `**加粗**` | 去掉格式，长度 ≥ 8 字的记为金句候选 |
| 有序 / 无序列表 | 去掉符号，保留文字 |
| `#` 标题 | 记为分屏候选，正文保留文字 |

## 结构映射

md 的结构可以直接变成画面：

| md | 视频元素 |
|---|---|
| frontmatter `title` | title 屏标题候选 |
| 一级 / 二级标题 | 章节分屏候选 |
| 加粗句（≥8 字） | quote 金句候选 |
| 列表项 | list 屏候选 |
| 图片路径 | image 屏素材候选 |

`brief.md` 会把它们分节列出来，由用户挑选。

## 体检指标

| 指标 | 计算 | 用途 |
|---|---|---|
| 字数 | 去掉空白后的字符数 | 判断要压缩多少 |
| 句子数 | 按 `。！？!?` 切分 | 判断节奏 |
| 平均句长 | 字数 / 句子数 | > 40 就要拆句 |
| 类型 | 字数比 + 平均句长 | A/B/C/D |

## 类型判定

```
target_chars = 目标秒数 × 4.5
ratio = 原文字数 / target_chars

ratio ≤ 1.15 且 平均句长 ≤ 32   → A（可直接口播）
ratio ≤ 3                        → B（压缩）
ratio ≤ 6                        → C（取核心段落）
ratio > 6                        → D（重写）
```

## 压缩策略（给 script 阶段参考）

| 类型 | 保留优先级 |
|---|---|
| B | 开头段、每个小标题下的第一句、结论段 |
| C | 只保留结论和最强的一个例子 |
| D | 丢弃论证过程，只留结论和数字 |

**永远优先保留：数字、对比、结论、金句。**
**优先删除：背景铺垫、举例展开、代码、引用。**
