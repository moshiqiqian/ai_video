# 文案写法

## 时长换算

中文 TTS 约 **4.5 字/秒**（含停顿）。

| 目标时长 | 字数 | 适合 |
|---|---|---|
| 15 秒 | 60–70 字 | 抖音爆款、金句 |
| 30 秒 | 120–140 字 | 常规短视频 |
| 45 秒 | 190–210 字 | 时评、科普 |
| 60 秒 | 260–280 字 | 深度点评 |
| 90 秒 | 380–420 字 | 长视频 |

**先定时长再写字数。** 写完再删最费时。

## 三种结构

### 时评 / 观点

```
钩子      一句反常识或冲突
事实      发生了什么，给关键数字
解读      为什么会这样，谁受影响
观点      你的判断，明确站边
```

### 科普 / 解释

```
问题      观众不知道但该知道的
答案      一句话回答
拆解      分层解释（2–3 层）
收尾      一句话总结
```

### 产品 / 介绍

```
痛点      用户现在的麻烦
方案      你的东西怎么解决
能力      三条具体的
行动      下一步做什么
```

## 写作规则

| 规则 | 原因 |
|---|---|
| 单句 ≤ 40 字 | 超过会呛气，听感断裂 |
| 数字用阿拉伯数字 | “3200 亿”比“三千二百亿”念得准 |
| 每两句至少一个句号 | 没标点就没有停顿，时间轴切不开 |
| 少用括号和引号 | 部分 TTS 会念出来 |
| 英文词一句最多一个 | 中文模型读英文名容易错 |
| 不要写“如下”“见图” | 视频没有图可看 |

## 压缩已经有的文章

优先级从高到低：

```
数字 / 对比  >  结论  >  金句  >  举例  >  背景铺垫
```

通常做法：

1. 保留首段和结论
2. 每个小标题只留第一句
3. 删掉所有“值得注意的是”“综上所述”
4. 长句拆成两句，反而更口语

## 常见毛病

**字数对了但念出来还是长**
→ 数字多、英文多。适当再砍 10%。

**念出来很生硬**
→ 句尾全是句号。把一部分改逗号，语气才连。

**听起来像念稿**
→ 加口语标记：「你发现没有」「说白了」「这事儿」。

**TTS 念错专有名词**
→ 换中文谐音写，或接受（字幕用原文）。
