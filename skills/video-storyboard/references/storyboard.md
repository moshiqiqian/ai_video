# 分镜规则

## 屏数与节奏

| 总时长 | 建议屏数 | 每屏时长 |
|---|---|---|
| 15 秒 | 3–4 | 3–5 秒 |
| 30 秒 | 4–5 | 5–7 秒 |
| 45 秒 | 5–7 | 6–9 秒 |
| 60 秒 | 6–8 | 7–10 秒 |

**每屏不要低于 1.5 秒**，观众来不及读。低于这个就会被 `check` 拦住。

## 六种画面类型

### title — 开场

```json
{ "type": "title", "kicker": "栏目名", "title": "标题", "sub": "副标题" }
```

- `kicker` ≤ 20 字，可省略
- `title` ≤ 16 字，实际最好 8–10 字
- `sub` ≤ 28 字

用于第一屏，或者章节切换。

### list — 要点

```json
{ "type": "list", "mark": "number", "rows": ["要点一", "要点二"] }
```

- **最多 2 行**，3 行以上逐行出现会跟语音错位
- 每行 ≤ 12 字
- `mark` 可写 `number`（自动 1/2/3）、`✓`、`•`、`→`

### quote — 金句

```json
{ "type": "quote", "text": "真正的风险，是没人借钱。" }
```

- ≤ 24 字，一屏一句
- 用于观点、结论、转折
- 这一屏不显示字幕（避免重复）

### image — 图片

```json
{ "type": "image", "src": "架构图", "caption": "结构说明" }
```

- `src` 是素材库里的名字（先 `media.py add`）
- `caption` 可省略
- 图片区自动给字幕留 150px 底部空间

### video — 视频片段

```json
{ "type": "video", "src": "演示" }
```

静音播放，用于录屏、B-roll。

### ending — 结尾

```json
{ "type": "ending", "title": "关注我", "accent": "关注", "sub": "每周三期" }
```

- `accent` 会在 `title` 里高亮成主题色
- 目标：留一个动作（关注、评论、看下一期）

## 时间对齐

```json
{ "type": "list", "start_at_sentence": 4, "rows": ["..."] }
```

含义：**第 4 句开始时切到这个画面**。

- 句子编号来自 `tranbuild/script.json`（跑 `--transcribe` 生成）
- 第一屏不用写，默认从 0 秒开始
- 编号必须递增

不确定第几句 → 打开 `build/tranbuild/script.json` 看 `sentences` 数组的下标 +1。

也可以写文字：

```json
{ "type": "quote", "at_text": "真正的风险" }
```

程序会在转写里模糊匹配这句话。英文品牌名 ASR 常认错，用中文片段匹配更稳。

## 分镜的常见错误

| 错误 | 后果 | 修法 |
|---|---|---|
| 一屏 4 行 | 第 3、4 行和语音错位 | 拆成两屏，每屏 2 行 |
| 标题 20 字 | 超出画面 | 砍到 10 字以内 |
| 清单行 18 字 | 换行、挤 | 拆成两个要点 |
| 两屏都用 quote | 连续大字，节奏单调 | 中间插一屏 list 或 image |
| 结尾 1 秒 | 一闪而过 | 至少给 2.5 秒 |
| 没有开头钩子 | 前 3 秒划走 | 第一句直接抛冲突 |

## 一份好的分镜长什么样

```
0.0 – 3.2    title   降息之后 / 三个被忽略的信号
3.2 – 9.8    list    银行息差收窄 / 存款利率跟降
9.8 – 16.4   image   利率走势图
16.4 – 24.0  quote   真正的风险，是没人借钱
24.0 – 31.5  list    M2 增速 / 信贷需求
31.5 – 38.0  ending  关注我，看懂财经
```

特点：**每屏一个动作**，类型交替（title → list → image → quote → list → ending），没有连续两屏同类型。
